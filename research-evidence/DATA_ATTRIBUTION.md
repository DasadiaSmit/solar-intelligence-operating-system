# Weather data attribution

Weather data are supplied by [Open-Meteo.com](https://open-meteo.com/), using ECMWF ERA5 reanalysis from the [Copernicus Climate Change Service](https://climate.copernicus.eu/). The preserved source records contain retrieval times, requested years, units, raw responses and adaptation provenance.

Open-Meteo states that its API data are available under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), with credit, a licence link and an indication of changes. See the [provider licence page](https://open-meteo.com/en/licence), checked 25 October 2026. No endorsement is implied.

The raw archive is retained alongside transformed scientific records. Project transformations include validation and unit/calendar alignment, documented interval-midpoint geometry, removal of leap day for the 8,760-hour comparison, and a documented snow-depth proxy. Generation, candidate comparisons and reports are derived project outputs, not measured plant readings or unmodified weather observations.

Provider data licensing is distinct from the licence of the provider's software. This package does not incorporate Open-Meteo server source. Application dependencies retain their respective licences; no new public licence grant for the project's own source is added by this private repository update.
