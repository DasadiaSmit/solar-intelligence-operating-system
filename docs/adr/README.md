Architecture Decision Records preserve why shared technical choices were made.

Create `NNNN-short-kebab-title.md` from the requirements in [`governance/DECISION_PROCESS.md`](../../governance/DECISION_PROCESS.md). Records are immutable once accepted; superseding work links the old and new records.

1. Versioned scientific result and browser transport boundaries.
2. Behavior-preserving extraction of the operating shell and workspace packages.
3. Live provider snapshot integration with annual simulation.
4. PET Assistant evidence/tool boundary before model integration.
