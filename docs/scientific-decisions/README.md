# Scientific Decision Records

Scientific Decision Records preserve formulas, data policies, validation evidence and claim boundaries.

Create `SDR-NNNN-short-kebab-title.md` using [`governance/DECISION_PROCESS.md`](../../governance/DECISION_PROCESS.md). A record must link the affected code, tests, dataset/model/calculation versions and documentation.

The first planned records should reconcile:

1. Irradiance decomposition/transposition documentation with executable code.
2. Horizon and shading semantics.
3. Inverter part-load method and naming.
4. Representative-year selection method and terminology.
5. Drift monitoring status and zero-variance R² behavior.
